Usage: osx-traffic-stats [options]

Real-time macOS menu bar network traffic monitor and CLI engine.

Options:
  -i, --interface <name>   Specific interface to monitor (default: active physical)
  -r, --interval <duration> Refresh interval (1s, 2s, 5s) [default: 1s]
  -j, --json               Output raw JSON lines for pipelines and Prometheus
  -c, --csv                Stream comma-separated metrics to stdout
  --data-cap <size>        Data cap threshold with native alerts (e.g. 500GB, 1TB)
  --graph                  Launch with floating Cocoa realtime traffic HUD
  -v, --version            Display version information and exit
  -h, --help               Print this usage reference

[ 0% Telemetry ]

100% offline and private. No cloud phone-homes, zero third-party trackers, no crash analytics.

[ Native C / Sysctl ]

Reads direct Darwin kernel network counters via sysctl and BPF sockets. Zero Electron, zero Python overhead.

[ < 4MB RSS Memory ]

Microscopic footprint. Idles in macOS menu bar without battery penalty, thermal throttling, or CPU wakeups.

Engineered For Developers & Power Users

Everything you need to monitor macOS network throughput without bloated helper daemons.

Floating Cocoa HUD Graph

Real-time 60-point hardware-accelerated traffic graphs with 1m, 5m, and 15m intervals, always-on-top mode, and peak tracking.

Data Cap Sentinel

Configure daily, weekly, or monthly bandwidth quotas. Receive native macOS Notification Center alerts at 75%, 90%, and 100%.

Process Attribution

Integrates with macOS nettop to reveal top network-consuming applications directly in the menu bar and HUD.

Unicode Sparklines

Live transfer rates rendered as sleek Unicode sparklines directly in your menu bar beside the system clock.

Scriptable Pipelines

Pipe formatted JSON or CSV metrics into jq, Telegraf, VictoriaMetrics, or terminal dashboards with ease.

Gatekeeper & Universal

Built natively for Apple Silicon (M1/M2/M3/M4) and Intel x86_64, ad-hoc signed, and ready for clean Homebrew Cask installation.

Quick Start & Documentation

Get running in seconds with Homebrew, standalone binary, or Go compiler.

RECOMMENDED

Homebrew Cask (Menu Bar App)

Installs the native OSXTrafficStats.app bundle into /Applications.

brew install --cask smford/tap/osx-traffic-stats
CLI UTILITY

Homebrew Formula (Terminal CLI)

Installs the command-line binary into your PATH for headless scripting.

brew install smford/tap/osx-traffic-stats
SYSTEM INTEGRATION

Launch at macOS Login

Enable background auto-start via native launchd user agent from the menu item or command line:

osx-traffic-stats --install-service
DEVELOPERS

Build from Source

Compile a universal binary locally using Go 1.22+ and Xcode Command Line Tools:

git clone https://github.com/smford/osx-traffic-stats.git && make package
